## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) copies `entry.png` to `/output/entry.png`. No network, deterministic — two runs write the same bytes. `generate_image.py` is the builder script that drew `entry.png` (Pillow, run on the build machine only) from the facts below.
